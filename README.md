# Adrián Valenzuela — Portfolio UX/UI

Web personal de portfolio para Adrián Valenzuela, diseñador UX/UI freelance.

Sitio estático (HTML/CSS/JS vanilla, sin frameworks ni build).

## Estructura

- `index.html` — contenido de la página
- `styles.css` — estilos
- `main.js` — interactividad (menú móvil, animaciones al hacer scroll, formulario de contacto)
- `.htaccess` — configuración para hosting Apache (compresión, caché, HTTPS)
- `assets/img/` — imágenes

## Publicar con GitHub Pages

1. Sube este repositorio a GitHub.
2. Ve a **Settings → Pages**.
3. En "Source", selecciona la rama `main` y la carpeta `/ (root)`.
4. Guarda; la web quedará publicada en `https://<usuario>.github.io/<repositorio>/`.
